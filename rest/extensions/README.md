# extensions

Operations for managing Directus extensions.

## Operations

- Query all installed extensions
- Update (enable/disable) an extension by ID
- Delete an installed extension by ID
- Search the marketplace registry
- Describe a registry extension
- Describe a registry account (an extension's publisher)
- Install an extension from the registry
- Reinstall an installed registry extension
- Uninstall a registry extension
